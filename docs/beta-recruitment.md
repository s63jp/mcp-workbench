# MCP Workbench — Beta Tester Recruitment

**GitHub:** https://github.com/s63jp/mcp-workbench


## What We're Building

**MCP Workbench** is a web-based testing platform for Model Context Protocol (MCP) servers — think "Postman for MCP."

MCP is Anthropic's open protocol that lets AI assistants (Claude, Cursor, VS Code Copilot) connect to external tools. MCP servers are exploding in popularity, but there's no easy way to test, validate, or debug them.

## What You'll Do

1. **Test our web interface** with real MCP servers you build or use
2. **Give feedback** on UX/UI — what's confusing, what works, what's missing
3. **Help shape the product** — your input directly influences our roadmap
